# TMR TechShop

Магазин техники на TMR Engine 0.1.

## Запуск на GitHub Pages
1. Загрузите все файлы и папки из этого архива в корень репозитория.
2. Откройте **Settings → Pages**.
3. Выберите **Deploy from a branch**, ветку `main` и папку `/(root)`, затем нажмите **Save**.
4. Дождитесь публикации и откройте адрес GitHub Pages.

Главная страница — `index.html`; исходная оболочка игры также доступна как `TMR.html`. Папки `mods` и `plugins` не входят в эту сборку.

Сохранение игрового прогресса в cookies включается только после согласия в окне cookies. Кнопка «🍪 Cookies» внизу страницы позволяет изменить выбор. При отказе cookies для игрового сохранения удаляются; для переноса прогресса используйте «Сохранить игру» и экспорт JSON.
Движок загружает `engine.json`, `games/tech-shop.json` и библиотеки из `libraries/`, поэтому структуру папок нужно сохранить.

## Локальный запуск
В корне папки выполните `python -m http.server 8000`, затем откройте `http://localhost:8000/`.

Сохранение по умолчанию хранится в браузере. GitHub Pages не позволяет игре записывать файлы прямо в репозиторий; для переноса сохранения используйте экспорт внутри игры, если он доступен.
