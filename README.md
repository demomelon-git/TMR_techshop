# TMR TechShop

Магазин техники на TMR Engine 0.2.

## Запуск на GitHub Pages
1. Загрузите все файлы и папки из этого архива в корень репозитория.
2. Откройте **Settings → Pages**.
3. Выберите **Deploy from a branch**, ветку `main` и папку `/(root)`, затем нажмите **Save**.
4. Дождитесь публикации и откройте адрес GitHub Pages.

Главная страница — `index.html`; та же оболочка доступна как `TMR.html`. Папки `mods` и `plugins` не входят в эту сборку.
Движок загружает `engine.json`, `games/tech-shop/game.json` и библиотеки из `libraries/` и `games/tech-shop/`, поэтому структуру папок нужно сохранить.

## Сохранение и cookies
Игровой прогресс сохраняется в cookies только после согласия в окне cookies. Кнопка «🍪 Cookies» внизу страницы позволяет изменить выбор. При отказе cookies для сохранения удаляются; для переноса прогресса используйте «Сохранить игру» (файл JSON) и «Загрузить игру».

- Без согласия игра ничего не пишет в cookies и в localStorage.
- Сохранение хранится в кодировке base64 (кириллица в URL-кодировке занимала бы в 2 раза больше места). Лимит — около 7,5 КБ: cookies уходят на сервер с каждым запросом, а серверы отклоняют слишком большие заголовки. Если сохранение не помещается (много модов и плагинов), игра покажет сообщение и предложит скачать файл.
- Сохранения прежней версии (0.1) читаются: формат определяется автоматически.
- Кнопка «Подключить папку» (Chrome и Edge на компьютере) записывает прогресс в файл `save/tmr_tech-shop.json` и не зависит от cookies.

## Локальный запуск
В корне папки выполните `python start.py`, затем откройте `http://localhost:8000/`.
GitHub Pages не позволяет игре записывать файлы прямо в репозиторий.
